# The Igni System

November 2025

## Introduction

The Igni system is a collection of software that provides a 3D user environment to Linux.

## Environment Variables

- `TVR_DISPLAY` points to a [TVrender](https://github.com/igni-project/tvrender) socket.
- `IGNI_CURSOR` points to a [CQP](https://github.com/igni-project/cqp) socket set to [forward it's messages to all connected clients](https://github.com/igni-project/udscast).
